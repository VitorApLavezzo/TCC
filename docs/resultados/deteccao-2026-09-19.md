# Benchmark de detecção

14 cenários executados pelo mesmo caminho de ingestão da coleta real em 173.5s.

## Matriz de confusão

| | Sistema avisou | Sistema ficou calado |
|---|---|---|
| **Havia problema** | 6 (acerto) | 2 (escapou) |
| **Não havia problema** | 3 (alarme falso) | 3 (acerto) |

## Métricas

| Métrica | Valor | Leitura |
|---|---|---|
| Precisão | 66.7% | dos avisos emitidos, quantos eram problema de verdade |
| Revocação | 75.0% | dos problemas existentes, quantos foram encontrados |
| F1 | 70.6% | equilíbrio entre as duas |
| Taxa de alarme falso | 50.0% | das situações normais, quantas geraram aviso |
